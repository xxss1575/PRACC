# SQL 공부 (My SQL)

# 1. SQL의 기초

1. - SQL을 사용하는 이유 : SQL을 사용하는 이유중에 가장 큰 이유는 막대하고 큰 데이터베이스를 관리하기위해 사용된다
  - 파이썬이나 엑셀같은 프로그램, 언어는 데이터를 관리할수있는 제한수가 있다 엑셀은 최대가 100만개 정도고 파이썬은 메모리를 기준으로 데이터량을 깎아먹기때문에 1GB만 돼도 파이썬으로 데이터를 관리하기 힘들어질것이다
  
# SQL 사용법, 알아야하는것  
  - 데이터베이스를 SQL같은 언어로 관리하고 수정,삭제,생성등을 편하게 해주는 소프트웨어를 (Database Management System) 줄여서 DBMS라고 부른다
  - My SQL 기본 작성 및 실행순서 SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT
  - 데이터 파일의 종류는 데이터 파일, 로그파일, 인덱스 파일, 설정파일, 메타데이터 파일 순으로 있고 각 파일마다의 종류
  - SQL DB에서 CRUD는 DB가 제공하는 기본 동작으로 생각하면 된다 
  - C(Create) 생성
  - R(Read) 읽기, 조회
  - U(Updata) 수정, 변경
  - D(Delete) 삭제

# SQL 동작하는법

- 1. 일단 첫번째로 SQL 동작할수있는 이유는 SQL에서 Show databases;사용하면 나오는
1. information_schema (메타데이터 관련정보 제공)

2. mysql
(1.서버 사용자의 계정, 권한 정보 저장)
(2.시스템 관련 레벨정보 저장)

3. performance_schema (서버 사용 성능 및 모니터링을 위한 정보 저장)

4. sys (performance_schema의 데이터를 단순화), (성능 분석을 위한 사용자 편의성 제공)

- 이 5개의 Database를 기반으로 돌아간다
- 그리고 SQL에서 코드가 작성된 문장을 쿼리(query)라고 부른다
- 첫번째에서 나오는 메타데이터는 데이터에 대한 데이터라고 보면된다
쉽게 말하면 테이블이 있다고 치면 이 테이블의 이름은 users고 age, email, name 컬럼이 포함, id정보 등 이런 데이터에 대한 구조를 데이터로 보여준다


# DB 종류
  - 1. 데이터 파일 (실제 데이터를 저장한다 (개인정보, 집 주소, 비밀번호같은 데이터들))
  - 2. 로그파일 (작업 내용을 저장 (어떤 코드가 작동했는지 어디서 오류가 났는지 등등)데이터 복구에 주로 사용
  - 3. 인덱스 파일(빠른 파일 검색, 탐색을 위해 사용)
  - 4. 설정파일 (DBMS의 구성과 운영설정을 저장)
  - 5. 메타데이터 파일 (데이터 베이스의 구조(데이블, 데이터타입, 관계 등...)에 대한 정보를 저장)

# 테이블 종류, 기능

테이블 명

고객   열 (칼람, 속성)
        ↓
-----------------------
아이디|이메일|성별|
  101   32.com 남자      
-----------------------    ← 행 (로우, 레코드, 튜플)
